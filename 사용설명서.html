1. 개요 및 시스템 구성

이 프로그램은 군종(군종병) 신우들의 예배 출석을 관리하기 위한 터치(키오스크) 방식의 웹 프로그램입니다. 참석자가 이름을 입력하면 즉시 출석 처리되고, 관리자는 명단·팀·결석·보고서 등을 한 화면에서 관리할 수 있습니다.

주요 기능

  • 예배 출석(체크인) : 이름 입력 → 본인 확인 → 출석 처리
  • 일요일 / 수요일 모드 : 서로 다른 예배(모드)별로 출석 기록 분리 관리
  • 명단(인원) 관리 : 신우 등록·수정·삭제, 검색·필터·정렬
  • 팀 · 소속 관리 : 소속 단위 일괄 이동, 이름 변경, 팀 생성·삭제
  • 일괄 출석 : 이름 목록 한 번에 출석 처리 (동명이인 직접 선택)
  • 결석 관리 : 수요 예배 결석자 사유 등록·조회
  • 보고서 생성 : 종합·A4·팀별 보고서, 서버 종료 시 자동 저장
  • 시간 동기화 : 시스템 시간 확인 및 인터넷(NTP) 시간 갱신

기술 구성

항목내용
서버Flask (Python) — 127.0.0.1:5000 에서 동작
데이터베이스SQLite (단일 파일, 별도 설치 불필요)
화면브라우저(키오스크 모드) — Chrome / Edge 전체 화면
보고서독립 HTML 파일 + 팀별 PNG 이미지 생성 가능

2. 설치 및 실행

2-1. 필요 환경

  • Windows PC, Python 3 설치 필요
  • 브라우저 : 구글 Chrome 또는 Microsoft Edge (키오스크 모드 사용)
  • 인터넷 시간 동기화를 위해 네트워크 필요(선택)

2-2. 의존 패키지 설치 (최초 1회)

프로그램 폴더에서 명령 프롬프트를 열고 아래를 실행합니다.

pip install -r requirements.txt

내용물은 Flask 하나뿐이며, 이미 설치되어 있다면 생략해도 됩니다.

2-3. 실행

프로그램 폴더에서 다음 배치 파일 중 하나를 더블클릭합니다.

파일용도
start_kiosk.bat정상(운영) 모드로 실행 — 서버 시작 후 Chrome/Edge를 전체 화면 키오스크로 엽니다.
start_kiosk_dev.bat개발(테스트) 모드로 실행 — 화면에 “(개발자 모드)” 표시가 나타납니다.
수동 실행: 명령 프롬프트에서 python app.py (운영) 또는 python app.py dev (개발)로도 실행하고, 브라우저에서 http://localhost:5000 을 엽니다.
모드 구분: 운영(commercial)과 개발(dev) 환경의 출석 기록과 보고서가 별도로 저장됩니다. 테스트 중 발생한 기록이 실제 예배 기록에 섞이지 않도록 하려면 테스트는 반드시 dev로 하세요.

3. 예배 참석자 출석 (체크인)

출석 화면은 참석자가 직접 사용하는 화면입니다. 관리자 인증(PIN) 없이 사용할 수 있습니다.

출석 절차

1. 상단에 예배 모드(일요일/수요일) 확인→ 2. 이름 입력→ 3. 본인 맞는지 확인→ 4. 출석 완료 메시지

단계별 동작

  • 이름 입력 : 입력란에 이름을 입력하면 동명이인 등 후보가 자동 추천됩니다. 추천 목록에서 선택하면 정확히 지정됩니다.
  • 본인 확인 : “본인이 맞으십니까?” 화면에서 맞습니다 / 아니요 선택.
  • 완료 : 출석이 저장되고 완료 메시지가 표시됩니다.
중복 출석: 같은 예배(모드)에 이미 출석한 경우 “이미 출석하셨습니다” 안내와 함께 중복 처리되지 않습니다.
명단에 없는 이름: 명단에 없는 이름은 출석 처리되지 않습니다. 먼저 관리자 화면의 명단 관리에서 등록해 주세요.

4. 관리자 로그인 (PIN)

메인 화면에서 관리자 영역을 누르면 숫자 키패드로 로그인하는 관리자 인증 화면이 열립니다.

로그인 방법

  1. 기본 관리자 PIN 1717 을 키패드로 입력
  2. 확인 누르기 → 관리자 홈으로 진입
PIN은 설정 파일에서 변경 가능: 프로그램 폴더의 config.py 에 ADMIN_PIN = '1717' 값이 있습니다. 보안을 위해 운영 시 반드시 다른 값으로 바꾸고, 수정 후에는 서버를 다시 실행하세요.
보안 동작 방식: 예배 출석(체크인)은 PIN 없이 누구나 가능하지만, 모든 관리 기능(명단·팀·결석·보고서·시간 등)은 로그인 후에만 사용할 수 있습니다. 관리자 로그인 상태에서는 각 요청에 PIN이 자동으로 포함되어 전송됩니다. 따라서 관리자 기능 URL을 주소창에 직접 입력해 접근해도 PIN 없이는 “관리자 인증이 필요합니다” 메시지와 함께 차단됩니다.

5. 예배 모드 전환 (일요일 / 수요일)

관리자 홈 상단의 “현재 모드”에서 예배 모드를 선택합니다.

  • 일요일 : 일요일 예배용 (해당 주의 일요일 날짜 기준)
  • 수요일 : 수요일 예배용 (해당 주의 수요일 날짜 기준)

모드를 바꾸면 메인 화면 상단의 표시(배지)도 함께 바뀌고, 이후 출석은 해당 모드로 기록됩니다. 모드 전환 시 안내 문구가 표시됩니다.

모드별 기준일: 일요일 모드는 일요일 날짜, 수요일 모드는 수요일 날짜를 기준으로 출석·보고서를 계산합니다. “이 날짜 보고서” 기능 등에서도 같은 기준이 적용됩니다.

6. 명단(인원) 관리

명단 관리 탭에서 모든 신우를 등록·조회·수정·삭제할 수 있습니다.

신규 등록

신규 등록 버튼 → 아래 입력 항목을 채우고 저장합니다.

항목설명
이름필수. 출석 시 입력하는 이름과 동일하게 등록
세례(영세)O (세례) / X (미세례)
소속드롭다운에서 선택
팀드롭다운에서 선택
기존 출석 교회이전에 다니던 교회
연락처전화번호
전역일자전역 예정일
생일MMDD 형식 (예: 0102) — 보고서의 생일자 목록에 사용
비고메모 · 새신우 태그(자동 관리)
군종병 여부체크 시 군종병으로 표시 (수요일 연속 미출석자 목록 등에 영향)

조회 · 검색 · 필터 · 정렬

  • 검색 : 이름·소속·팀 키워드 입력
  • 필터 : 소속 · 팀 · 세례(O/X/미기재) · 군종병(군종병/일반 신우)
  • 정렬 : No 순 / 이름 ↑↓ / 생일 ↑↓ / 팀 ↑↓

수정 · 삭제

  • 목록의 해당 행에서 수정(편집)을 눌러 정보를 변경·저장합니다.
  • 삭제를 누르면 확인 후 명단에서 제거됩니다.
  • 전역 처리된 신우는 별도의 아카이브(전역) 목록으로 이동하며, 필요 시 복원할 수 있습니다.

7. 출석 현황 조회

출석 현황 탭은 해당 예배(모드)의 출석 요약과 출석 명단을 보여줍니다.

  • 상단에 요약(출석 인원 등)이 표시됩니다.
  • 아래 표에 출석자 목록(이름·소속·팀·출석 시간 등)이 표시됩니다.
출석 현황은 현재 선택된 예배 모드(일요일/수요일)의 출석을 기준으로 조회됩니다.

8. 일괄 출석

여러 명을 한 번에 출석 처리할 때 사용합니다. 예배 시작 후 명단을 한꺼번에 체크할 때 유용합니다.

사용 방법

  1. 일괄 출석 탭 선택
  2. 이름을 한 줄에 하나씩 입력 (예: 여러 줄 붙여넣기)
  3. 출석 처리 클릭

처리 규칙:

  • 이름이 유일하면 바로 출석 처리됩니다.
  • 동명이인이 있으면 직접 올바른 사람을 선택하게 안내합니다.
  • 명단에 없는 이름이나 이미 출석한 이름은 결과에 구분하여 표시됩니다.

9. 팀 · 소속 관리

팀 관리 탭에서 소속(파트)과 팀을 체계적으로 관리합니다.

기능설명
소속 일괄 이동소속 → 선택한 팀으로 그 소속의 인원을 모두 이동
소속 이름 변경소속 이름 변경 (임시 소속을 변경하면 빈 ‘임시’ 소속이 자동 생성)
임시 소속 추가새 임시 소속 생성 (기본 이름: 임시)
팀 이름 변경팀 이름 변경
새 팀 만들기새 팀 생성
새신우 유지 기간새신우로 분류되는 기간(일) 설정 · 저장

새신우: 비고란에 자동 기록되는 ‘새신우(등록일)’ 태그로 관리됩니다. 설정한 유지 기간(기본 30일)이 지나면 자동으로 일반 신우로 분류되고, 지난 태그는 자동 정리됩니다.

10. 수요 결석 관리

수요 결석 관리 탭에서 수요일 예배의 결석자와 결석 사유를 관리합니다.

  • 날짜 선택 : ‘지난 수요일’, ‘지지난 수요일’ 버튼 또는 날짜 직접 선택. 기본은 가장 최근 지나간 수요일입니다.
  • 해당 수요일에 출석하지 않은 신우 목록이 표시됩니다.
  • 각 결석자에게 결석 사유를 등록(수정)하거나 삭제할 수 있습니다.
결석은 해당 모드(수요일)의 출석 기록을 기준으로 “출석에 없는 사람”을 자동으로 집계합니다.

11. 기록 · 통계 · 시간 관리

기록·통계·시간 탭은 과거 기록 조회, 출석 추가, 시간 관리 기능을 제공합니다.

날짜별 기록 조회

  • 조회/출석 날짜 선택 후 출석 기록 보기 → 해당 날짜의 출석 명단 표시
  • 이 날짜 보고서 → 해당 날짜 기준 보고서 생성(새 창)

임의 출석 추가

  • 특정 날짜 · 시각에 특정 신우의 출석을 관리자가 추가 기록합니다.
  • 직접 추가한 출석 기록은 목록에서 삭제할 수 있습니다.

시간 복구 (동기화)

  • 시간 확인 : 현재 시스템(로컬) 시간과 인터넷(NTP) 시간을 표시(읽기 전용).
  • 인터넷 시간으로 동기화 : NTP 서버에서 받아온 정확한 시간으로 시스템 시간을 맞춥니다.
시간 동기화 권한: 시스템 시간 변경은 관리자 권한이 필요할 수 있습니다. 안내가 뜨면 확인해 주세요. 네트워크가 없을 때는 동기화가 실패할 수 있습니다.

12. 보고서 및 출력물

관리자 홈 상단 버튼으로 보고서를 생성·열람하고, 필요한 형태로 출력하거나 저장할 수 있습니다.

버튼동작
보고서 보기종합 보고서를 새 창(HTML)으로 엽니다.
보고서 보기 (A4)A4 인쇄용으로 정리된 보고서를 새 창으로 엽니다.
팀별 보고서 내보내기팀 단위 보고서 파일들을 생성·내보냅니다.
보고서 저장 + 서버 종료현재 보고서를 저장한 뒤 서버를 종료합니다.

종합 보고서의 주요 항목

  • 예배 정보(모드 · 날짜) 및 총 출석 건수
  • 팀별 출석 인원 (이번 주) 및 팀 출석자 상세 명단
  • 연속 미출석자 명단 (1~4주) 수요일
  • 이달의 생일자 · 새신우 현황 일요일
  • 결석 사유 반영 (수요일 모드)

HTML 보고서 파일 저장 위치

  • 메인 보고서 : 프로그램 폴더의 군종_그룹관리_commercial.html / ..._dev.html
  • 날짜별 보관 : data\보고_commercial\ 폴더에 날짜별·팀별 파일로 보관
  • PNG 이미지 : 메인 + 팀별 보고서를 PNG로도 생성 가능
인쇄: 보고서는 HTML로 열리므로 브라우저의 인쇄(Ctrl+P)로 바로 출력하거나 PDF로 저장할 수 있습니다. A4 버전은 A4 용지에 맞게 정리되어 있습니다.

13. 데이터 저장 위치

항목위치
주요 데이터(명단·출석·결석 등)프로그램 폴더의 SQLite DB 파일 (군종.db, 군종.db.bak_…)
날짜별·팀별 보고서 보관data\보고_…\
메인 보고서 HTML군종_그룹관리_….html
보고서 템플릿report_template.html
백업 권장: 데이터베이스는 단일 파일이므로, 정기적으로 군종.db 파일을 별도 저장소로 복사해 두면 안전하게 백업할 수 있습니다.

14. 보안 (관리자 PIN)

  • 예배 출석(체크인)은 PIN 없이 누구나 사용할 수 있습니다.
  • 모든 관리 기능은 PIN 인증을 요구하며, 요청 헤더(X-Admin-Pin)로 검증됩니다.
  • PIN이 없거나 틀리면 “관리자 인증이 필요합니다.” 응답(401)으로 차단됩니다.
  • 로그인 상태에서만 관리 기능을 수행할 수 있으며, PIN은 구성 파일(config.py의 ADMIN_PIN)에서 관리합니다.
운영 시 반드시: 기본 PIN 1717을 운영 환경에 맞는 값으로 변경하고 서버를 재시작하세요.

15. 자주 묻는 문제와 주의사항

Q. “관리자 인증이 필요합니다.” 메시지가 나옵니다.

관리자 기능 URL을 주소창에 직접 입력해 접근했기 때문입니다. 관리자 기능은 PIN 없이 접근할 수 없습니다. 반드시 메인 화면의 관리자 영역 → PIN 로그인 후 사용하세요.

Q. 이름을 입력했는데 출석이 되지 않습니다.

  • 명단에 해당 이름이 등록되어 있는지 확인하세요(명단 관리에서 등록).
  • 동명이인이 있으면 추천 목록에서 본인을 정확히 선택하세요.
  • 이미 같은 예배에 출석한 경우 중복으로 처리되지 않습니다.

Q. 화면이 예배 모드와 다릅니다.

관리자 로그인 → 현재 모드에서 일요일/수요일을 올바르게 선택하세요.

Q. 시간이 맞지 않습니다.

관리자 로그인 → 기록·통계·시간 탭에서 인터넷 시간으로 동기화를 실행하세요 (관리자 권한·네트워크 필요).

Q. 보고서가 예전 날짜로 보입니다.

보고서는 선택한 날짜(또는 현재 모드의 기준일) 기준으로 생성됩니다. 기록·통계·시간 탭의 이 날짜 보고서를 확인하세요.

Q. 테스트 기록이 실제로 보입니다.

운영(commercial)과 개발(dev) 기록은 분리됩니다. 테스트는 start_kiosk_dev.bat(dev)로 실행하세요.

주의사항

  • 서버 종료는 관리자 화면의 보고서 저장 + 서버 종료를 사용하면 보고서를 남기고 종료됩니다.
  • 키오스크 전체 화면 종료: Ctrl+Shift+I 또는 Alt+F4 등으로 종료할 수 있습니다.
  • 브라우저를 새로 고침(Ctrl+F5)하면 최신 화면(스크립트)이 반영됩니다.
